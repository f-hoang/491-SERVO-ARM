## Summary
Our work involves both hardware and software, we will develop and build a robotic arm made of servos. It will be controlled through a program we build in C++ and Python for hardware control and visual identification respectively.

## Objectives
1. MODULE 1: Get a working program for the visual identification software (Python)
 - Test to verify that it works with our camera module
2. MODULE 2: Get a working program to control the arm directly (C++)
 - Purchase and build the arm
 - Test to verify that it works with our arm
3. Bridging the gaps between the 2 modules we've built
4. Rigorous testing phase, development of new test cases based on any issues that came up.
5. Profit(?)

## Detailed Specs
We plan to use a Raspberry Pi 4 to control the arm. The arm will be composed of 2 servo joints, 3D printed parts, and a claw to move and manipulate objects based on our desired objectives.
Python will be used for the identification aspect of our project, utilizing OpenCV for contour analysis.
